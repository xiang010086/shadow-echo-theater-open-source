# 影有回声｜无螺钉分块打印修订版

日期：2026-11-04。保留15.6英寸屏幕、15毫米屏厚、400×350×2毫米整片亚克力与原光路基准。连接只要求打印件和热熔胶，不要求螺钉、螺母、磁铁或热熔铜螺母。

## 文件入口

- `00_PRINT_FIRST_fit_coupons.3mf`：先打印的配合试件。
- `plates_3mf/`：按256毫米平台几何排盘的分盘文件，方向已调整；**不是已切片工程或G-code**，仍需选择现场打印机、耗材、层高并检查支撑/裙边。
- `stl_print/`：单件STL，已经调整打印方向并落到Z=0；不要按这些坐标尝试组装。
- `review/assembly.step`：毫米制装配CAD，含屏幕和亚克力参考体。
- `review/assembly.glb`：米制预览，含屏幕和亚克力参考体。
- `review/assembly_geometry_only.3mf`：毫米制装配位置，只用于核对装配；不要整套直接打印。
- `review/结构预览.png`、`review/分块编号图.png`：结构与编号图。
- `零件清单.csv`：逐件包络、数量与几何实体体积。几何体积不是切片耗材估计。
- `review/build_report.json`、`review/interference_report.json`、`review/export_verification.json`：构建和独立回读检查结果。
- `source/`：可重建源码。原41文件压缩包和旧版模型未覆盖。

## 本轮结构变化

1. 开槽托板由3毫米改为6毫米，顶面仍为Z=55，底面Z=49；15毫米屏幕上表面仍为Z=70。
2. 托板下有三条10毫米高、6毫米宽的纵向加强筋，以及六处24×24毫米接触垫。
3. 底板上一体打印六个24×24毫米支撑柱，柱顶Z=39，与托板接触垫及加强筋底面接触。位置为X=-150、55、150，Y=125、300。中间支撑避开X=0分块缝。该位置需现场避让实际开发板及线缆。
4. 原8毫米底板保留；底板分块连接片位于底面。六个独立4毫米脚垫使底部支承面与连接片底面保持同高，脚垫放在支撑柱正下方。
5. 顶板改成分四块组装的浅盘套盖，可整体取下。盖面4毫米、下翻边12毫米、单边名义间隙0.4毫米。盖子外形约447.2×357.2毫米；本轮增加了盖边和外侧连接片，外包络不是严格440×350毫米。
6. 前面板保持可取下、无孔、固定挡光上沿Z=160；下段外表面前移4毫米与上段齐平，便于平放打印。四个插榫仍对应原来的侧板插槽。前面板自身两块胶接，整块不与侧板胶死。
7. 侧板上下轨道继续一体打印，2.4毫米槽宽和原45度方向保留。侧板分块接缝由外侧双柱桥接片定位并加固。
8. 所有大件切缝名义宽0.24毫米。定位柱单边间隙0.3毫米，给试装与热熔胶留余地；实际适配由试件决定。

## 分块与连接件数量

|编号前缀|部件|数量|
|---|---|---:|
|B_base|底板，含承重柱|4|
|L_side / R_side|左、右侧板，含轨道和托板槽|各4|
|K_back|后板|4|
|T_tray|加强托板|4|
|C_lid|浅盘箱盖|4|
|F_front|前面板|2|
|S_stop|亚克力前限位|2|
|P_foot|底部脚垫|6|
|J_light|50×18毫米双柱定位桥接片|35|
|J_heavy|60×24毫米双柱定位桥接片|16|

定位桥接片底座跨在两块板的接缝上，两根方柱插入各自板件的方槽。定位柱负责对齐及传递部分剪力，热熔胶固定桥接片和板面。方槽保留板底，不是贯穿孔。它不是机械自锁结构，必须胶接。现场若配合过紧，先修整或修改小连接片，不要强行掰薄板。

`J_light_print_35.stl` 是一个单件模板，需要35个；`J_heavy_print_16.stl`同理。两盘连接片3MF已放足数量，不要同时重复打印模板和整盘。

## 先打印试件

试件盘包含轻型/重型连接片与配合板、2.4毫米亚克力槽、6.6毫米托板槽、0.4毫米单边间隙的箱盖止口样件。

用现场同一打印机、同一耗材先试。检查定位柱能否插入、箱盖止口能否取下，再用现有亚克力边角试槽。试件通过后才开大件。试件过松或过紧，修改源码中的配合参数并重新导出，不要在热熔胶凝固前靠手扶整箱纠正轨道。

## 热熔胶与装配

1. 打印时按文件名标记每一块；编号图是从各板件外表面/托板底面观察，右侧板方向与左侧板相反。
2. 各板先分别拼成整面：在平整基准上对齐，逐个插入桥接片，少量热熔胶固定。等胶冷却后再翻面，确认接缝没有折角。
3. 底板接缝从底面装重型连接片；脚垫装在六个支撑柱正下方。支撑柱本体已经一体打印，不需另粘柱子。
4. 托板倒放拼好，连接片位于底面，纵筋和六个接触垫也在底面；不要在屏幕接触面堆胶。
5. 将左右侧板和后板装到拼好的底板，检查垂直与方正，再胶接固定接缝。避开托板槽、亚克力槽、接口窗、前板插槽。
6. 加强托板从前方滑入两侧槽，筋和接触垫底面沿柱顶滑过；先空载试装。如公差导致卡住，现场调整接触位置或薄垫。不要粘死托板，便于检修。
7. 装入屏幕和线缆，观察支承位置是否压住屏幕背面的凸起或散热口，再做载荷与热运行测试。
8. 沿一体轨道装入亚克力，加回前限位；安装前面板与箱盖。前限位、前面板与箱盖不与主体胶死。
9. 内侧贴黑卡遮光，避开槽和配合面。外侧连接片留在结构外侧，不侵入光路。

每个侧板切缝方向有两个分离的连接片用于约束转动，但定位间隙意味着仍需直尺/平整基准检查。胶接前用整片亚克力试滑入，确认槽没有明显错台；槽中不灌胶。

## 现场仍需确认

- 屏幕重量未知，本版不标额定承重；先用分布接近的等重载荷测试，再放真实屏幕。四面保持方正、支撑柱与托板接触垫都实际接触。
- 所有打印件默认材料、壁数、填充、层高、热熔胶型号尚未指定；打印人员应结合实际材料和设备设置。胶枪高温喷嘴不直接抵住薄板或亚克力。
- 不以箱盖提起整机；搬运时托住底部。用胶接外壳装机后再次检查接缝。
- 底仓开发板型号未知；六柱和纵筋应按现场设备避让，保留实际散热与插拔空间。
- 几何排盘不等于切片通过；打印时间、耗材重量和支撑量由现场切片器计算，本包不虚报。
- 现有屏幕发光区域、真实反射亮度、杂散光、视角、热运行和胶接强度仍需实物调试。

## 重建

Python依赖：cadquery 2.8.0、cadquery-ocp 7.9.3.1.1、trimesh、numpy、matplotlib；渲染用Windows微软雅黑字体。运行 `source/build_revision.py`，再运行 `source/render_and_verify.py`。

`fetch_cad_wheels.py`仅为本次临时环境下载辅助程序，从官方PyPI取轮子并核对官方SHA-256；不会修改打印机或发送打印任务。
