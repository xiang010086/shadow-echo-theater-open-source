# 配置与验收

默认未提供.private目录或任何密钥，speech_route在缺少配置时返回disabled，不会自动选择付费服务。

如自行接入兼容服务，可按源码tts_organizer_worker.py/voice_engine.py的接口要求，在本机src/.private/创建speech_route.json（provider为organizer）和organizer_key.txt（自己的Key），目录0700、Key文件0600。当前适配的网关地址与模型名写在源码中，不保证未来可用；如服务不同需自行调整，不能使用比赛已结束的额度或他人Key。使用其他服务应先查看其计费和数据条款。

麦克风语音在本地采集与Vosk识别，复杂表达的识别文本会发送到配置的理解服务；原始录音不由本程序上传云端。明确短选择及预制回应可走本地缓存。无配置时可用鼠标完整走剧情分支。

单元回归：在仓库根目录运行python -m unittest discover -s src/tests -p "test_*.py"。浏览器回归另需Playwright及浏览器。测试中模拟麦克风/AI的结果不能当作真人识别准确率。
