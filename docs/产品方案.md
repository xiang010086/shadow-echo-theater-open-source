# 影有回声｜当前产品方案

更新：2026-11-04。依据用户在本轮对话中确认的方向修订，作为当前产品定义的主入口。用户明确认可产品初心、产品定义、客户方向、扩展路线及PPT讲解顺序；本次同时纳入角色对话、剧情参与、音乐与锣鼓的完整演出要求。首版呈现方式已逐项选定；具体制作、语音、部署与异常处理继续讨论。

## 一句话定位

**影有回声是一座融合AI对话、光影呈现与传统表演语言的非遗互动戏台。它让公众能够看戏、与角色交流，并把自己的想法带进演出；从皮影开始，探索更多非遗文化的当代表达。**

愿景关键词：AI＋具有悬浮观感的光影呈现＋非遗文化互动展示。当前光学采用屏幕与45°透明反射板形成的反射虚像；对外技术说明应准确表达，不宣称可绕行观看的体积全息。

## 1. 产品初心：为什么想做

**用更轻量、更现代的方式，让更多公众接触、理解并参与非遗文化。**

可直接用于介绍的表述：

> 我希望人们接触非遗时，除了观看和听介绍，还能与其中的人物产生交流，把自己的想法带进表演。
> 因此，我想把传统文化内容、具有悬浮观感的实体戏台和AI结合起来，创造一种容易接近、能够回应、可以反复体验的文化入口。
> 从皮影开始，让观众看见一出戏、认识其中的文化，并参与一次新的演出。

增加一种接触和参与非遗的方式，让更多人有机会进一步喜欢它。公众传播是主线，不限定为儿童教育产品；儿童、家庭、游客等均是可能的参与者。数字体验可引导观众进一步接触真实技艺与真人表演。

真人演出排期、场馆互动需求、组织成本等属于待访谈确认的需求线索。不得把这些推测写成已经证实的市场痛点。

## 2. 产品定义：看戏、入戏、共创

一座有表演、有交流、有共创的AI互动光影戏台。

|体验|观众得到什么|产品提供什么|
|---|---|---|
|看戏|感受皮影的形、声、动作和故事|有音乐、锣鼓、人物表演的完整选段|
|入戏|与角色交流，理解人物和文化|角色回应观众，结合当前情境解释或提问|
|共创|把自己的想法带进演出|AI编排回应、行动及后续情节，戏台演出来|

三部分可以发生在同一次连续体验中，不预设必须做成三个独立菜单或分别开发三个系统。

看戏让人愿意靠近，交流让人建立联系，共创让人愿意继续参与。实体舞台负责呈现，文化内容提供人物、表演与故事依据，AI负责理解与回应，并参与可执行的演出编排。

长期产品保留更多故事与创作可能；当前不承诺任意人物、任意动作、任意题材均能即时生成。

## 3. 完整演出：画面、动作、台词、音乐与锣鼓

首个Demo采用皮影表现形式。角色应保留轮廓、镂刻纹样、透光色彩、侧身造型及分节动作等经过资料研究的视觉与表演依据，具体参考需在制作时选择。

|声音层|作用|设计要求|
|---|---|---|
|配乐|建立场景和情绪，支持故事推进|根据情节进入、退出和调节音量，不遮盖人声|
|锣鼓与动作声音|配合出场、动作、转折和收束，形成表演节奏|与可见行动对应；具体用法结合所选风格与素材核对|
|角色人声|承载人物性格、剧情与交流|音色稳定、对白清楚，与动作及情节接续|

互动时为观众留出说话空间；收到回答后，角色回应接上动作与声音，再进入下一段演出。不得用敲锣、通用欢迎词代替针对观众表达的有效回应。

音乐、锣鼓与声音应形成经过试听的项目资产和排演安排。提前准备声音片段并按节点调用，是下一步可评估的实现候选；现场生成音乐、专业唱腔复原均未被确定为比赛必需能力。

普通话数字改编、原创小戏与传统选段分别标明。具体传统选段、地方风格、素材来源及使用条件仍待确认。

## 4. 比赛版要证明的体验

当前已通过逐项讨论确定：小班主先接待并推荐已有剧目，首出采用《狐假虎威》互动改编；演出使用暖色幕布、戏台边框与彩色皮影人物，保留音乐、锣鼓、人声与动作。

声画片段提前制作，运行时由AI理解观众表达、回应并衔接后续。第一版安排一次关键剧情互动：在段落间收住演出，小班主给出几个方向，观众仍用自己的话建议，影响后续剧情。

路演采用按住按钮说话、松开提交；本次比赛同时计划加入人体感应自动招呼。自动招呼不等于自动录音，具体检测与控制待实现。主办方表中列有5个LD2450，可优先确认领用。

连续流程与逐项选择见[首版呈现决策与主办方材料](影有回声_首版呈现决策与主办方材料_2026-11-04.md)。原《过桥》示例不采用。已选两条验证路线汇合到共同结局，狐狸与老虎对白推进，小班主串场；联网生成小班主短回应并配音，断网用预录引导、按键选择与本地播放。角色素材数量、片段拆分、时长及最终台词仍待落实，见[台词与片段初稿](狐假虎威_互动皮影戏_台词与片段初稿.md)。

验收方向：
- 开场演出有观看价值，小班主能自然引入参与。
- 回应与观众表达相关，在支持范围内影响可见行动或剧情。
- 人物、道具状态、台词、动作、音乐与锣鼓接续。
- 传统故事依据与互动改编部分说明清楚。
- 等待、错误、断网与传感器重复触发有明确处理。
- 所有能力按实机验证结果说明，不以渲染或设想代替。

## 5. 谁来使用，谁可能购买

2026-11-08用户明确首期商业模式：以学校和图书馆作为目标采购客户，由机构采购设备供儿童自主体验；我方提供设备、配套剧目及后续内容更新和维护服务。不得将“进入学校/图书馆”写成我方出资免费铺设常设设备。后续探索非遗馆、文旅空间与地域文化内容定制。这里是目标商业模式，不表示已有采购或订单；早期活动租赁等旧候选不再作为当前路演主线。

产品愿景面向公众；商业验证需要寻找具体组织者与预算负责人。

|候选客户|体验者|可能采购的价值，仍需验证|
|---|---|---|
|非遗馆、文化馆、博物馆|参观公众、家庭、游客|增加可以反复开放、与展览内容结合的互动体验|
|非遗体验空间、研学机构|活动参与者|获得可组织、可重复开展的文化活动工具|
|文旅空间、主题展览|游客、现场观众|以当地人物、故事和文化内容形成体验点|
|学校、公共教育空间|学生、社区公众|支持文化欣赏、提问和参与创作|

优先寻找非遗展示或体验空间开展验证，与公众传播定位贴近；学校是可能场景，不把整个产品限定为儿童教育设备。该优先级是当前验证方向，不代表已获采购意向或已证明哪个市场更容易进入。

候选交付：设备＋文化内容＋互动体验设计＋安装维护。早期探索活动租赁、试点或采购，依据真实客户反馈确定收费方式。当前没有确定售价、订单或销量预测。

需要确认的客户问题：由谁组织和操作；在哪个时段使用；一天服务多少人；环境声与网络条件；内容如何更新；谁审批和付款；相对平板、视频或真人活动的采用理由。

## 6. 未来变化与扩展

### 2026-11-08 用户明确的故事创作目标

长期希望观众能自己书写故事，由AI协助整理剧本、编排角色、动作与声音，呈现专属于这位观众的皮影戏。期望从收到故事到演出准备完成约两三分钟；这是待开发、待验证的目标，不是已测生成速度，也不是指演出只能持续两三分钟。

本次只有两天制作时间，先以《狐假虎威》的预制声画和支持的行动路线，验证观众表达与角色回应、后续演出的联系。当前原型未完成完整的现场故事生成，不能将预制分支描述为已支持观众任意自写故事。后续故事创作与跨非遗门类拓展均需考虑内容质量、文化审校、素材与执行范围。

|扩展方向|路径|需要新增的工作|
|---|---|---|
|内容扩展|皮影→京剧、豫剧及其他地方戏曲、非遗|分别制作与审核造型、唱念、身段、声音、故事和知识|
|参与深化|看与问→影响剧情→共同编演及多人参与|对话、故事状态、执行与内容质量的验证|
|场景适配|桌面近距离体验→场馆常设、巡展、地方文化定制|重新验证观看条件、接待能力、声音、维护与运行成本|

长期积累：经过文化审校的内容、可复用的表演素材、对话与演出衔接的方法，以及真实场景中的运行经验。跨门类扩展不是简单换皮；当前原型不代表已经支持京剧、豫剧或大型场馆部署。

## 操演还原修订（2026-11-04）

用户明确要求以已收集的真实皮影资料还原造型结构和操演，不把“下方操杆／上方提线”作为自由视觉选项。用户选A保留大纹样的可读性，已有狐狸样图仅作纹样比较，不作为最终可操演影人。

后续按具体样本建立分件、关节、杆位和动作关系；动物不套用人形固定杆数，不把加装饰杆、持续抖动或普通卡通骨骼运动当作完成还原。制作路线仍为电脑预制并导出视频，设备播放，不增加未经讨论的机械机构或实时物理仿真。

具体依据、复核范围与制作要求见[真实皮影操演还原](真实皮影操演还原_依据与修改要求.md)。
