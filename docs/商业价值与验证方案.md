# 影有回声｜商业价值与验证方案

更新：2026-11-04。与[当前产品方案](../../01_项目方案/影有回声_当前产品方案.md)一致。客户排序、交付内容、收费与验证计划均为待验证方向，不代表已有客户、订单或市场结论。

## 产品与价值

初心是用更轻量、更现代的方式，让更多公众接触、理解并参与非遗文化。产品以AI互动光影戏台承载看戏、入戏和共创，首个Demo从皮影切入，保留形、声、动作和演出节奏。不限定为儿童教育设备。

社会价值落在公众的接触、理解与参与；商业价值需要进一步证明某个组织愿意为可重复提供的体验付费。

## 谁体验、谁组织、谁付款

|候选客户|体验者|待验证的采购价值|访谈对象|
|---|---|---|---|
|非遗馆、文化馆、博物馆|公众、家庭、游客|可反复开放、与展览结合的互动体验|教育、展陈、活动与运营负责人；预算与审批主体需另核实|
|非遗体验空间、研学机构|活动参与者|可组织、可重复开展的文化活动工具|经营者、活动或课程负责人|
|文旅空间、主题展览|游客与现场观众|地方人物、故事与文化体验点|空间运营方、项目方或展陈集成商|
|学校、公共教育空间|学生、社区公众|文化欣赏、提问与参与创作|教师、活动负责人及实际预算负责人|

优先寻找能够安排真实测试的非遗展示或体验空间。该方向与当前公众传播定位贴近，并不意味着已经证明机构愿意采购或采购更容易。

## 候选交付与收费

设备＋文化内容＋互动体验设计＋安装维护。早期探索活动租赁、具体试点或采购；试用时长、支持内容、现场服务与验收写清后，再讨论真实价格。

后续可评估新增内容、地方文化定制和维护服务。收费应对应实际持续交付，不预设必须订阅。当前没有确定售价或销售预测，原型采购成本不等于量产成本。

每台交付贡献＝实际收入－硬件装配－内容制作与授权分摊－运输安装－培训渠道－预计售后等直接成本。还需核算研发、获客和管理成本。

## 核心验证问题

- 组织者目前怎样提供文化体验，哪里费时，谁审批和付款？
- 观众是否主动靠近、愿意交流、理解自己的参与如何影响演出？
- 相同内容放在平板上与放进实体戏台，体验差别是否足够支持采用？
- 一次能服务多少人，是否需要工作人员持续介入？
- 嘈杂环境、网络变化和反复使用时是否稳定，维护由谁承担？
- 内容怎样审校和更新，与当地主题如何结合？
- 负责人愿意尝试什么具体交付包，预算从哪里来，验收条件是什么？

真人演出和真实技艺提供重要文化经验；本产品探索可反复开放的补充入口，并引导进一步接触。不得假定传统节目贫乏、所有观众不喜欢手工，或仅靠新奇外观就能形成持续需求。

## 验证路径

先访谈可直接接触的组织者，回顾近期真实活动；再安排小规模试用，记录参与、理解、等待、人工介入和故障。条件允许时与同内容平板体验对照。

提出具体试点交付与价格后，记录预算、采购流程与采用条件。口头认可不当作采购证据。依据结果调整客户优先级与收费，而非提前编写销量或回报。

## 未来扩展与积累

内容：皮影→京剧、豫剧及地方非遗，各自制作和审核表演、声音与知识。

参与：看与问→影响剧情→共同编演和多人参与。

场景：桌面→常设、巡展和地方定制，各自重新验证观看、声音、接待、维护与成本。

长期积累经过文化审校的内容、可复用表演素材、对话与演出衔接方法及真实运行经验。目前这些属于建设方向。
